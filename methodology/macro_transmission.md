# 宏观经济传导分析框架

## 框架目标

提供一套结构化的方法，用于分析武装冲突对宏观经济的中长期传导影响。与金融市场影响框架（market_impact.md）互补——市场影响侧重短期价格反应，本框架侧重**实体经济的结构性变化**。

> **风险声明**：宏观经济分析涉及大量不确定性，本框架仅用于分析和学习目的，不构成任何经济政策或投资建议。

---

## 一、传导链条总览

冲突对宏观经济的传导可概括为以下链条：

```
武装冲突
    │
    ├─→ 供给冲击 ─→ 能源/粮食/原材料价格上涨 ─→ 成本推动型通胀
    │                                              ├─→ 企业利润压缩
    │                                              └─→ 居民实际购买力下降
    │
    ├─→ 贸易中断 ─→ 供应链断裂 ─→ 生产停滞/延迟
    │              ├─→ 航运受阻 ─→ 物流成本飙升
    │              └─→ 制裁壁垒 ─→ 贸易格局重塑
    │
    ├─→ 财政冲击 ─→ 军费增加 ─→ 财政赤字扩大
    │              ├─→ 难民安置支出
    │              └─→ 援助与重建支出
    │
    ├─→ 信心冲击 ─→ 投资推迟/撤回 ─→ 资本形成下降
    │              ├─→ 消费收缩 ─→ 需求下降
    │              └─→ 资本外逃 ─→ 货币贬值
    │
    └─→ 劳动力冲击 ─→ 人口伤亡/流离失所 ─→ 劳动力短缺
                     └─→ 难民流入目的国 ─→ 劳动力供给变化
```

## 二、六大传导渠道详析

### 2.1 能源传导渠道

**核心问题：冲突是否影响全球能源供给？程度和持续时间如何？**

分析要素：
- 冲突区域的能源产量占全球比重
- 能源运输通道（管道、海峡、运河）是否受影响
- OPEC+等组织的产量调整意愿和能力
- 战略石油储备的释放空间
- 替代能源（包括可再生能源加速）的切换周期

传导路径：
```
能源价格上涨 → 电力/运输成本上升 → 几乎所有行业成本增加
                                    → 居民能源支出占比上升
                                    → 能源进口国贸易逆差扩大
                                    → 能源出口国获得超额收入
```

### 2.2 粮食传导渠道

**核心问题：冲突是否威胁全球粮食安全？谁最脆弱？**

分析要素：
- 冲突区域的粮食出口占全球比重（小麦、玉米、食用油等）
- 化肥供应是否受影响（氮肥、钾肥）
- 黑海/地中海等关键粮食运输通道的状况
- 受影响最大的粮食进口国（中东、北非、撒哈拉以南非洲）
- 粮食价格上涨对社会稳定的二次效应

**脆弱性评估：** 粮食进口依赖度高 + 外汇储备低 + 财政补贴空间小 = 高风险国家

### 2.3 贸易与供应链传导渠道

**核心问题：冲突导致多少全球贸易"消失"？通过什么机制中断？恢复需要多久？**

本渠道分为三个层次分析：**咽喉要道中断 → 出口"消失" → 供应链传导**。

#### 2.3.1 海上咽喉要道评估

全球贸易高度依赖少数海上咽喉要道。冲突一旦波及这些节点，影响将远超交战国本身。

**全球关键咽喉要道清单：**

| 咽喉要道 | 正常通行量 | 全球贸易占比 | 替代路线 | 替代成本 |
|----------|-----------|------------|---------|---------|
| 霍尔木兹海峡 | ~2,000万桶/天石油 + 全球20% LNG | 海运石油27%，LNG 20% | 沙特/UAE管道（容量有限） | 替代仅覆盖约14% |
| 红海/苏伊士运河 | 全球海运贸易12-15% | 欧亚贸易核心通道 | 好望角绕行 | +10-14天，+$2,000/TEU |
| 马六甲海峡 | 全球海运石油25% | 东亚能源命脉 | 龙目/巽他海峡 | +2-3天 |
| 巴拿马运河 | 全球海运贸易5% | 美洲东西海岸连接 | 苏伊士或好望角 | 大幅绕行 |
| 土耳其海峡 | 黑海石油/粮食出口通道 | 乌克兰/俄罗斯粮食出口 | 陆路/管道（有限） | 高 |

**咽喉要道中断分析步骤：**

1. **识别受影响通道**：冲突区域覆盖或威胁哪些咽喉要道？
2. **量化通行量**：该通道正常承载多少贸易（分品类：石油、LNG、集装箱、散货）？
3. **评估中断程度**：完全关闭 / 部分通行 / 仅保险撤出（实质关闭但技术上未封锁）？
4. **计算替代路线容量**：管道、绕行航线能吸收多少？净缺口是多少？
5. **评估中断持续时间**：基于军事态势和保险市场恢复速度

**关键认知：中断机制不一定是物理封锁。** 保险撤出、航运公司自主避航、运费暴涨导致的经济性不可行——这些"软封锁"的效果与物理封锁等同，但更难被军事手段解决。

#### 2.3.2 交战国/波及国出口"消失"量化

冲突不仅中断航运通道，还直接导致交战国和波及国的出口产能中断。

**分析步骤：**

1. **列出所有受直接军事影响的国家**（交战国 + 被波及国）
2. **逐国识别关键出口品及全球占比**

| 国家 | 关键出口品 | 全球供给占比 | 出口依赖的通道 | 替代出口路径 | 当前出口状态 |
|------|-----------|------------|--------------|-------------|------------|
| | | | | | 正常/部分中断/完全中断 |

3. **按品类汇总"消失"的全球供给**

| 品类 | 消失的供给量 | 占全球供给% | 每日贸易额 | 替代来源可行性 |
|------|------------|-----------|-----------|--------------|
| | | | | 高/中/低/无 |

4. **识别"没有替代"的品类** — 这些是冲击最集中的领域
   - 某些商品的产能集中度极高（如卡塔尔LNG、巴林铝）
   - 某些商品的出口100%依赖受影响通道（无管道替代的LNG）
   - 这些品类的价格反应将最剧烈、持续最久

#### 2.3.3 贸易依赖度脆弱性矩阵

不同国家/地区对中断贸易的依赖度不同，需逐一评估。

**脆弱性评估模板：**

| 国家/地区 | 对中断品类的进口依赖度 | 战略储备天数 | 替代供应商可行性 | 财政缓冲能力 | 综合脆弱性 |
|----------|---------------------|------------|----------------|------------|-----------|
| | 占进口的%或绝对量 | 天 | 高/中/低 | 高/中/低 | 极高/高/中/低 |

**脆弱性 = 依赖度高 + 储备低 + 替代少 + 财政弱**

典型高脆弱性特征：
- 能源进口单一来源依赖（如巴基斯坦99%LNG来自卡塔尔）
- 战略储备不足（低于30天）
- 外汇储备有限，难以在现货市场高价抢购替代供应
- 国内财政无力补贴能源价格上涨

#### 2.3.4 供应链多阶传导

贸易中断的影响不止于直接断供，还会层层传导：

```
一阶：直接断供
    某品类无法进口 → 直接使用该品类的行业停产/减产

二阶：成本传导
    能源/原材料价格上涨 → 中间品成本上升 → 几乎所有行业成本增加

三阶：航运挤出
    航线绕行 → 运力被占用 → 不相关航线的运费也上涨 → 全球物流成本普涨

四阶：保险传染
    冲突区域保险撤出 → 邻近区域保险费率上升 → 更大范围的贸易摩擦成本增加

五阶：信心冲击
    供应链不确定性 → 企业推迟下单/囤货 → 牛鞭效应（需求信号放大）
```

#### 2.3.5 贸易恢复滞后效应

**核心认知：停火 ≠ 贸易恢复。** 贸易恢复的速度远慢于军事降级。

**恢复瓶颈链条：**

```
停火/军事降级
    ↓ [滞后1: 安全评估期]
    航运公司评估安全性（数天-数周）
    ↓ [滞后2: 保险恢复]
    保险公司恢复战争风险覆盖（数周-数月）← 这通常是最慢的环节
    ↓ [滞后3: 运力重新部署]
    船舶从替代航线调回（数周）
    ↓ [滞后4: 港口/设施修复]
    被损坏的港口、管道、设施修复（数周-数月）
    ↓ [滞后5: 库存重建]
    沿途国家补充耗尽的库存（数月）
    ↓
    贸易恢复至冲突前水平
```

**历史参照：**
- 2024年红海危机：胡塞停火后，主要航运公司花了3-6个月才逐步恢复红海航线
- 1991年海湾战争：科威特油田灭火和恢复生产花了约8个月
- 波斯湾水雷（如果存在）：扫雷作业可能需要数月至一年

**评估要素：**

| 恢复瓶颈 | 预估滞后时间 | 关键条件 |
|----------|------------|---------|
| 航运公司恢复通行 | 停火后1-4周 | 需要安全保障+军舰护航 |
| 保险市场恢复覆盖 | 停火后1-3个月 | 需要持续无事故记录 |
| 运力重新部署 | 2-6周 | 取决于全球运力紧张程度 |
| 受损设施修复 | 数周-数月 | 取决于损坏程度 |
| 库存恢复至正常 | 3-6个月 | 取决于品类和各国储备水平 |

#### 2.3.6 行业级供应链影响模板

对具体受影响的行业，使用以下模板分析：

| 受影响行业 | 依赖的关键输入 | 冲突区域供应占比 | 替代来源 | 切换时间 | 成本增量 | 终端价格传导 |
|-----------|--------------|-----------------|---------|---------|---------|-------------|
| | | | | | | |

**分析时需注意：**
- 某些行业的库存周期很短（如航空燃油），冲击来得更快
- 某些行业有长期合约保护，短期冲击被缓冲，但合约到期后面临重新定价
- "友岸外包"（friend-shoring）和供应链多元化可能因冲突加速

#### 2.3.7 农业投入品传导链（化肥/氨/尿素）

**核心认知：化肥冲击是"隐形时间炸弹"——价格信号在3-6个月后才传导至粮食价格，12-18个月后才显现为粮食安全危机。**

这条传导链之所以被系统性忽视，是因为：
- 化肥没有金融期货市场（无实时价格信号吸引媒体关注）
- 从化肥涨价到粮食减产存在**一整个种植季的滞后**
- 影响最大的是发展中国家小农户（低媒体可见性）

**传导路径：**

```
冲突中断化肥供应（天然气→氨→尿素产业链）
    ↓ [即时]
    化肥现货价格上涨（尿素+26-50%，氨+41%）
    ↓ [1-3个月]
    进口国化肥库存消耗 → 农户面临采购决策
    ↓ [3-6个月 — 下一个种植季]
    农户选择：① 高价购入（成本传导至粮价）② 减少施肥（减产）③ 转种低肥作物
    ↓ [6-12个月 — 收获季]
    粮食产量下降 + 粮食价格上涨
    ↓ [12-18个月]
    粮食进口依赖国出现食品通胀 → 社会稳定风险
```

**关键区分：**

| 层次 | 时间窗口 | 影响机制 | 受影响群体 |
|------|---------|---------|-----------|
| 化肥价格冲击 | 即时-1个月 | 供给中断+运费上涨 | 化肥进口国、贸易商 |
| 农业成本传导 | 3-6个月 | 种植成本上升或施肥不足 | 农户、农业企业 |
| 粮食价格传导 | 6-12个月 | 减产+成本转嫁 | 消费者、粮食进口国 |
| 粮食安全危机 | 12-18个月 | 库存耗尽+持续高价 | 低收入国家、脆弱人群 |

**分析要素：**
- 冲突区域的天然气/氨/尿素产能占全球比重
- 受影响国家的化肥库存天数（通常仅覆盖一个种植季）
- 下一个种植季的时间窗口（北半球3-5月，南半球9-11月）
- 替代供应来源及切换时间（中国尿素出口政策、摩洛哥磷肥产能）
- 受冲击最大的农作物品种和依赖国

#### 2.3.8 传导可见性分级框架

**核心认知：不同传导链的"市场可见性"差异巨大，这导致某些高冲击传导被系统性低估。**

冲突的经济冲击中，有些立刻成为头条新闻（油价飙升），有些则在数月甚至数年后才被注意到。分析者需要主动识别"低可见性、高冲击"的传导链。

**传导可见性分级：**

| 可见性等级 | 特征 | 典型品类 | 分析者应对 |
|-----------|------|---------|-----------|
| **Ⅰ — 即时可见** | 有期货市场、金融媒体实时报道、价格秒级更新 | 原油、天然气、黄金、主要股指 | 默认覆盖，无需特别关注遗漏 |
| **Ⅱ — 延迟可见** | 有行业报价但无期货、专业媒体报道、价格日/周级更新 | LNG现货、航运运费（BDI）、战争险保费 | 需主动纳入监测，非金融媒体默认覆盖 |
| **Ⅲ — 低可见** | 无公开报价、仅行业内部知晓、价格月级更新 | 化肥（尿素/氨）、工业气体（氦气）、船用燃料（VLSFO） | **需专门设立监测**，通过行业报告、采购经理访谈获取 |
| **Ⅳ — 隐形** | 冲击存在但暂时无价格信号、通过非价格渠道传导 | 化肥→粮食产量（滞后1年）、氦气→半导体产能（滞后3-6月）、保险撤出→贸易量（非价格壁垒） | **需用传导链模型主动推演**，而非等待价格信号 |

**低可见性品类的识别方法：**

1. **列出冲突区域所有出口品**（不仅限于大宗商品）
2. **检查全球集中度**：该品类冲突区域产能占全球>15%？
3. **检查替代性**：是否存在非冲突区域的替代供应？切换成本和时间？
4. **检查期货市场覆盖**：有无公开交易市场？若无 → 自动标记为低可见性
5. **检查终端影响**：该品类是否是某个关键产业链的不可替代投入？

**实战经验（2026年美伊冲突验证）：**
- 氦气（Ⅲ级）：无期货、无日报价，但卡塔尔停产导致全球半导体产能受限 → 冲突第7天才被分析覆盖
- 船用燃料VLSFO（Ⅲ级）：价格翻倍但几乎无金融媒体报道 → 直接推高全球物流成本
- 化肥→粮食（Ⅳ级）：冲突第13天仍未成为主流关注 → 6-12月后可能成为最大冲击之一

#### 2.3.9 时间索引脆弱性曲线

**核心认知：国家/地区的脆弱性不是静态的——随着冲突持续，储备消耗、合约到期、库存见底，脆弱性会持续恶化。**

§2.3.3的脆弱性矩阵是一个时间点的快照。但实际分析中，需要追踪脆弱性随时间的变化曲线，识别"临界点"——即某个国家/地区从"可承受"突然跌入"危机"的时间节点。

**时间索引脆弱性评估模板：**

| 国家/地区 | T+0（冲突爆发） | T+2周 | T+1月 | T+3月 | T+6月 | 关键临界点 |
|----------|---------------|-------|-------|-------|-------|-----------|
| | 脆弱性等级 | | | | | 何时从"可控"变为"危机" |

**驱动脆弱性恶化的因素：**

1. **储备消耗**：战略石油储备、天然气储备、粮食库存的天数倒计时
   - 示例：科威特储油仅18天 → T+18天即面临短缺
2. **长期合约到期**：合约价保护期结束后，需以现货价重新采购
   - 示例：LNG长约通常按季度定价 → 下一季度面临重新定价冲击
3. **保险周期**：战争险保单通常7天一续 → 每7天是一个潜在中断节点
4. **季节性因素**：冬季取暖需求、种植季化肥需求 → 冲击放大
5. **财政缓冲耗尽**：补贴政策的财政可持续性 → 补贴取消时社会冲击陡增

**脆弱性曲线的典型形态：**

```
脆弱性
  ↑
  │          ╱─── 阶梯式恶化（储备耗尽、合约到期等离散事件）
  │        ╱
  │      ╱
  │    ╱
  │  ╱──── 线性恶化（持续消耗型）
  │╱
  └──────────────→ 时间
       ↑         ↑
    冲突爆发   临界点（从可控→危机）
```

**实战经验（2026年美伊冲突验证）：**
- 韩国：冲突第1天脆弱性"中等"（有30天石油储备）→ 第11天KOSPI熔断（-5.96%）→ 脆弱性已升至"高"
- 巴基斯坦：冲突前已是"高脆弱性" → 随着LNG库存消耗，预计T+3周进入"极高"
- 日本：储备较充裕（约150天） → 但LNG依赖使其在T+2月后脆弱性显著上升

#### 2.3.10 空运模态转换传导

**核心认知：海运中断不仅影响海运货物——高价值、时间敏感货物会转向空运，推高全球空运成本，形成跨模态传导。**

当海上咽喉要道中断时，部分货物会从海运切换到空运。这种模态转换本身成为一个独立的传导渠道：

**传导路径：**

```
海峡/航线中断
    ↓
    部分高价值货物转空运（电子元件、药品、生鲜、急需零部件）
    ↓
    空运需求激增 → 空运运力紧张 → 空运费率飙升（可达+80-100%）
    ↓
    ├─→ 转空运货物的物流成本暴增 → 终端价格上涨
    ├─→ 原本使用空运的货物被挤出或涨价 → 跨行业传染
    └─→ 航空货运公司运力重新调配 → 某些航线运力下降
```

**分析要素：**
- 哪些品类最可能从海运切换到空运？（单价高、时效性强、体积/重量比高）
- 全球空运剩余运力有多少？（客机腹舱 vs 专用货机）
- 空运费率的基线和弹性（正常$2-4/kg → 危机时$8-15/kg）
- 空运能替代多少海运量？（通常不足1%，但对特定品类可达30-50%）
- 冲突是否影响航空航线本身？（如飞越禁区导致绕飞，增加燃油和时间成本）

**实战经验（2026年美伊冲突验证）：**
- 海湾地区空运费率+84%（冲突前$2.50/kg → $4.60/kg）
- 电子元件、医药原料成为主要转空运品类
- 中东上空飞越禁区导致欧亚航线绕飞，客机腹舱运力间接减少

### 2.4 财政传导渠道

**核心问题：冲突如何改变各国政府的财政支出结构？**

分析要素：
- **参战国**：军费激增、战时经济动员、经济控制措施
- **盟国**：军事援助支出、安全开支增加（如NATO成员国2%目标）
- **邻国**：难民安置成本、边境安全支出
- **全球**：人道主义援助、战后重建基金

财政影响评估：
- 军费增量占GDP比重
- 财政赤字变化与融资来源（发债、印钞、削减其他支出）
- 对社会支出（医疗、教育、养老）的挤出效应
- 长期债务可持续性影响

### 2.5 资本流动传导渠道

**核心问题：冲突如何改变全球资本的流向和配置？**

分析要素：
- 外国直接投资（FDI）的撤离与重新配置
- 资产组合投资（portfolio）的避险流动
- 被制裁国家的资本账户冻结效应
- "安全资产"需求变化对利率的影响
- 外汇储备多元化趋势（去美元化讨论）

关键判断：
- 资本流动是暂时性恐慌还是结构性重配？
- 哪些国家/地区可能成为资本流动的受益者？
- 全球金融体系碎片化的风险有多大？

### 2.6 劳动力传导渠道

**核心问题：冲突如何影响劳动力供给和人口结构？**

分析要素：
- **参战国**：战斗伤亡、劳动年龄人口外流、女性劳动参与率变化
- **难民接收国**：劳动力供给增加（但技能匹配问题）、工资压力
- **全球**：移民政策变化、人才流动格局重塑

### 2.7 数字经济传导渠道

**核心问题：冲突如何通过数字基础设施和网络空间影响实体经济？**

随着全球经济对数字基础设施的依赖程度加深，网络攻击和数字服务中断已成为冲突传导的独立渠道，其影响可能跨越地理边界。

分析要素：
- **数字基础设施中断**：云服务商在冲突区域的服务撤出或降级，影响依赖其基础设施的企业（包括第三国企业）
- **网络攻击的经济损失**：针对关键基础设施（能源、金融、交通）的网络攻击造成的直接经济损失和修复成本
- **数字供应链断裂**：软件服务中断、技术授权撤销、开源生态分裂等"数字脱钩"
- **网络安全支出激增**：政府和企业被迫大幅增加网络安全投入，挤出其他投资
- **数字贸易壁垒**：数据本地化要求、跨境数据流动限制、科技制裁导致的数字市场碎片化

传导路径：
```
冲突引发网络攻击/数字制裁
    │
    ├─→ 云服务/SaaS中断 → 企业运营中断 → 生产力损失
    ├─→ 金融系统遭攻击 → 支付/清算延迟 → 交易摩擦成本上升
    ├─→ 通信基础设施受损 → 数字经济活动萎缩
    ├─→ 数字供应链断裂 → 技术替代成本 → 创新速度下降
    └─→ 网络安全军备竞赛 → 企业/政府安全支出膨胀 → 挤出生产性投资
```

**数字经济脆弱性评估模板：**

| 行业/部门 | 对云服务的依赖度 | 对跨境数据流的依赖度 | 网络攻击暴露面 | 数字替代方案成熟度 | 综合脆弱性 |
|-----------|----------------|--------------------|--------------|--------------------|-----------|
| | | | | | |

## 四、时间维度分析

### 短期（0-6个月）：冲击与应对

- 价格冲击最为剧烈
- 政府采取紧急应对措施（战略储备释放、临时补贴、出口管制）
- 供应链中断的即时影响
- **分析重点**：冲击的规模和初始应对的有效性

### 中期（6个月-2年）：调整与适应

- 经济主体开始适应新现实（寻找替代供应商、调整生产流程）
- 通胀的二次效应（工资-价格螺旋风险）
- 货币政策的滞后效应显现
- 财政支出结构的调整
- **分析重点**：适应的速度和代价

### 长期（2年+）：结构性重塑

- 全球供应链的永久性重构
- 能源转型加速或延迟
- 国际经济秩序的调整（贸易集团、货币体系、国际组织改革）
- 参战国的经济重建轨迹
- **分析重点**：哪些变化是不可逆的？新的均衡是什么样的？
