## 一、咽喉要道评估（§2.3.1）

### 1.1 霍尔木兹海峡 — 从"实质关闭"到"选择性封锁"

| 评估项 | 第7天（3/6） | 第10天（3/9） | 变化 |
|--------|-------------|-------------|------|
| 通行状态 | 实质关闭：油轮流量-80%+ | **选择性封锁**：IRGC区分"敌国"vs"非敌国" | 质变：出现差异化管理 |
| 日通行量 | ~0 艘油轮 | 3/7仅3艘；3/8-9有零星通行 | 仍接近归零 |
| 滞留船只 | 150+ | **~700艘**（海峡两侧） | 急剧恶化 |
| 武力威胁 | IRGC宣称"海峡关闭" | 3/7击中化学品船PRIMA（实际动武） | 从威胁升级为执行 |
| 保险覆盖 | 主要P&I club 72小时通知取消中 | **全面生效**：覆盖已撤销 | 保险封锁成为主要瓶颈 |

**关键新发展："选择性封锁"的含义**

IRGC 3月5日和3月8日两次声明：海峡仅对美国、以色列及其西方盟友关闭。这意味着：

1. **中国运营船只可以通行** — 利比里亚籍但中国运营的Sino Ocean通过广播中国身份成功通行
2. **这不是物理封锁，而是政治筛选** — 伊朗有能力控制但选择性放行
3. **创造了一个"灰色地带"** — 挂方便旗的船只如何归类？中国买方通过第三方操作的船只呢？

**分析判断**（置信度：中）：
- 选择性封锁降低了全面战争的"完全切断"风险
- 但**保险市场不认可这种区分** — P&I club的取消是区域性的，不区分船旗国
- 因此，即使IRGC"允许"通行，大多数船只仍然**无法获得保险**而无法航行
- **净效果：与全面封锁差异不大**，除非出现针对性的保险解决方案

### 1.2 红海/苏伊士运河 — 二次中断

| 评估项 | 状态 |
|--------|------|
| 通行状态 | 重新中断：胡塞武装2/28宣布恢复攻击 |

| 替代路线 | 好望角绕行（+10-14天，+$2,000/TEU） |
| 与霍尔木兹的叠加效应 | 这两条通道同时中断意味着从波斯湾到欧洲的**所有路径都受阻** |

### 1.3 印度洋 — 新增战场

- 美潜艇在斯里兰卡海域击沉伊朗军舰 → 传统上安全的印度洋航线现在也有战争风险
- 这可能进一步推高保险费率，即便是绕行好望角的替代路线

### 2.3 "没有替代"的品类识别

**LNG是当前冲突中最没有替代的品类**：

1. 卡塔尔LNG**100%依赖海运出口**（不同于石油可以用管道），且100%通过霍尔木兹海峡
2. 全球LNG产能已满负荷，美国LNG出口设施已在最大产能运行
3. 即使卡塔尔设施修复，**没有保险的LNG船无法出航**
4. 恢复至少需要一个月（卡塔尔自己的评估：重启2周+满产能2周）
5. 高度依赖卡塔尔的国家（巴基斯坦99%、印度46%）面临真正的能源危机

**原油虽然量大，但有部分替代**：
- SPR释放可提供短期缓冲
- 美国/加拿大/巴西增产可填补部分缺口（但需3-6个月）
- 沙特有部分管道可绕行

### 3.2 保险传导链验证

```
2/28 冲突爆发 + 船舶遇袭（PRIMA等5+艘油轮受损、2人死亡）
    ↓
3/1 主要P&I club发出72小时取消通知
    ↓
3/3 VLCC运费已冲至$423,736/天历史新高（+94%）
    ↓
3/5 保险覆盖正式撤销生效
    ↓
3/7 海峡日通行量降至3艘 → 实质为零
    ↓
3/9 当前状态：
    物理上：IRGC声称"选择性开放"
    保险上：❌ 全面关闭（无保险=无法合法航行/进港/卸货）

    → 保险市场成为比军事封锁更有效的贸易阻断机制
```

**关键认知**：伊朗IRGC的"选择性开放"政策被保险市场的全面撤出所否定。即使IRGC允许某艘船通行，没有保险的船无法：
- 进入任何主要港口
- 在目的港卸货
- 获得银行信用证支持

### 3.3 保险恢复时间估算

| 恢复前提条件 | 估算时间 | 依据 |
|------------|---------|------|
| 冲突降级/停火 | 未知 | 当前无降级信号 |
| 停火后安全评估 | 1-2周 | 保险公司需评估残余风险 |
| 风险模型重建 | 2-4周 | 再保险商需"从零开始重建风险模型"（行业声明） |
| 逐船逐航次重新承保 | 4-8周 | "每艘寻求海湾通行的船必须逐航次单独重新承保" |
| 条约级产能恢复 | 2-3个月 | "在条约层面撤回的产能必须通过谈判恢复——多方顺序流程" |

**总估算**：即使明天停火，保险市场恢复正常覆盖需要**2-4个月**。

**历史参照对比**：
- 2024年红海危机中，保险费率在胡塞停火后3-6个月才逐步回落
- 当前情况比红海危机严重得多（船只实际被击中、人员死亡、P&I全面撤出 vs 红海仅保费上涨）

## 七、油价风险溢价拆解（§2.1.3）

### 7.1 风险溢价拆解

```
布伦特当前价格：$91/桶

基本面公允价值（无冲突）：~$65-70/桶（参考冲突前$73-74水平减去此前已有的风险溢价）

战争风险溢价：$91 - $67.5 = ~$23.5/桶

风险溢价隐含假设：
- 900万桶/天退出市场（~全球供给9%）
- 市场隐含中断持续时间：约4-6周（基于远期曲线贴水结构）
- 如果中断持续3个月+：溢价应更高 → 市场可能低估
```

### 7.2 市场定价合理性判断

| 信号 | 观察 | 解读 |
|------|------|------|
| 油价涨幅 vs 供应中断 | +24-31% vs 9%供给消失 | 基本匹配历史弹性系数 |
| 远期曲线 | 贴水加深（backwardation） | 市场认为短缺是**暂时的** |
| VIX | 24.56（+16%），未破30 | 恐慌程度**中等**，未进入极端恐慌 |
| 黄金 | $5,400→回落→$5,079区间 | 避险需求已部分回吐，市场"习惯"了冲突 |

**综合判断**（置信度：中低）：

市场正在定价"基准情景"——冲突持续4-6周后通过某种方式降级。**但市场可能低估了以下尾部风险**：

1. **保险恢复滞后** — 即使停火，贸易恢复需2-4个月，但远期曲线仅隐含4-6周中断
2. **海湾产油国被迫减产的二阶效应** — 如果储油持续满载，减产将进一步扩大（伊拉克已-60%）
3. **LNG短缺无替代** — 卡塔尔LNG停产+1个月恢复期+保险恢复期 = 至少2-3个月LNG短缺
4. **选择性封锁的不确定性** — IRGC政策可能随时改变（一艘船被击中就足以重新冻结通行）

**如果上述尾部风险实现，油价目标区间：$100-120+**
