## 一、冲突波及范围与全球贸易地图

### 1.1 受直接影响的贸易通道

本次冲突同时影响了全球两大海上咽喉要道，这在现代贸易史上前所未有：

```
                     全球海运贸易示意

    欧洲 ←──── 苏伊士运河/红海 ←──── 亚洲
         ❌ 胡塞武装恢复威胁
         （全球海运贸易12-15%）

                                  波斯湾 → 霍尔木兹海峡 → 印度洋 → 亚洲
                                           ❌ IRGC封锁+保险撤出
                                          （全球石油20%、LNG 20%）

    替代路线：好望角（+10-14天航程，+$2,000/TEU附加费）
```

| 通道 | 正常贸易量 | 当前状态 | 影响范围 |
|------|-----------|---------|---------|
| **霍尔木兹海峡** | 2,000万桶/天石油（占全球海运石油27%）+ 全球LNG贸易20% | **实质关闭**：油轮流量下降80%+，150+船只锚泊等待 | 石油、LNG、石化、铝 |
| **红海/苏伊士运河** | 全球海运贸易12-15% | **重新中断**：胡塞武装2/28宣布恢复攻击，Hapag-Lloyd/MSC/CMA CGM暂停通行 | 集装箱、散货、所有品类 |
| **印度洋** | 连接中东-亚洲的主航道 | **战斗区域**：美潜艇在斯里兰卡海域击沉伊朗军舰 | 全部东西向贸易 |

**历史对比**：
- 2024年红海危机：仅影响一条通道（红海），全球贸易影响约$1万亿
- 2026年当前：**同时影响两条通道+印度洋出现海战** — 现代全球化以来最严重的海运中断

### 1.2 受影响的国家与地区贸易图谱

**直接交战国：**

| 国家 | 全球贸易角色 | 关键出口品 | 出口规模 | 当前状态 |
|------|------------|-----------|---------|---------|
| **伊朗** | 全球石油储量10%、天然气储量15% | 原油、凝析油、石化产品 | 石油出口$430亿/年（约1.7百万桶/天） | **出口近乎归零** |
| **以色列** | 高科技出口国 | 半导体、软件、钻石、军工 | 出口$670亿（2024） | 部分中断 |

**被波及国（出口受阻）：**

| 国家 | 关键出口品 | 全球份额 | 当前状态 |
|------|-----------|---------|---------|
| **卡塔尔** | LNG | 全球LNG贸易**20-25%**；世界第二大LNG出口国 | **大部分生产暂停**（设施遭袭） |
| **阿联酋** | 石油、铝、转口贸易 | 全球铝产能约3%；迪拜是中东最大转口港 | 遭800枚弹药袭击，港口受损 |
| **巴林** | 铝、炼油产品 | 全球铝产能约1.5%（Alba是世界最大单体铝冶炼厂之一） | 炼油厂被击中，Alba宣布不可抗力 |

| **沙特阿拉伯** | 石油 | 全球石油出口约15%；霍尔木兹出口占37.2% | 部分出口可走东西管道（260万桶/天容量） |
| **伊拉克** | 石油 | 全球石油出口约5%；霍尔木兹出口占22.8% | **鲁迈拉油田关停**（最大油田） |

## 二、从霍尔木兹海峡"消失"的贸易量

### 2.1 石油贸易

**正常通行量**：约2,000万桶/天（2024年数据）

| 出口国 | 经霍尔木兹出口占比 | 日均通行量 | "消失"的贸易额（按$80/桶） |
|--------|------------------|-----------|--------------------------|
| 沙特 | 37.2% | ~740万桶 | ~$5.9亿/天 |
| 伊拉克 | 22.8% | ~460万桶 | ~$3.7亿/天 |
| 阿联酋 | 12.9% | ~260万桶 | ~$2.1亿/天 |
| 伊朗 | 10.6% | ~210万桶 | ~$1.7亿/天 |
| 科威特 | 10.1% | ~200万桶 | ~$1.6亿/天 |
| **合计** | **93.6%** | **~1,870万桶** | **~$15亿/天** |

**每天约$15亿的石油贸易被中断。**

**替代路线容量**：
- 沙特东西管道（Petroline）：~500万桶/天容量，其中约260万桶/天可用于绕过海峡
- 阿联酋阿布扎比-富查伊拉管道：~150万桶/天
- 合计替代容量：约260万桶/天（仅能补偿约14%的中断量）

**净缺口：约1,600万桶/天的石油运输无替代路线** — 这是全球石油消费量的约16%。

### 2.2 天然气/LNG贸易

**正常通行量**：全球LNG贸易的约20%

| 出口国 | 经霍尔木兹LNG出口 | 全球占比 | 主要买家 |
|--------|------------------|---------|---------|
| **卡塔尔** | 9.3 Bcf/天 | ~20% | 日本、韩国、中国、印度、欧洲 |
| **阿联酋** | 0.7 Bcf/天 | ~1.5% | 亚洲 |

**关键问题**：卡塔尔LNG**没有替代出口路线**。不像石油有管道可绕过海峡，LNG必须通过海运经霍尔木兹海峡运出。卡塔尔的LNG出口**100%依赖这条通道**。

加上卡塔尔两处设施被袭击导致生产暂停，这是**双重打击**：即使海峡恢复，产能也需要时间修复。

**对各地区的LNG冲击**：

| 地区 | 卡塔尔LNG依赖度 | 冲击评估 |
|------|----------------|---------|
| 巴基斯坦 | 进口LNG的99% | **灾难性** — 可能出现大规模停电 |
| 孟加拉国 | 进口LNG的72% | **极严重** |
| 印度 | 重要来源之一 | 高 |
| 日本 | 重要来源 | 高（但有SPR和多元化供应） |
| 韩国 | 重要来源 | 高 |
| 欧洲 | 俄乌后LNG替代来源之一 | 中-高（库存尚充足，但补库困难） |

### 2.3 铝贸易

| 来源 | 全球产能占比 | 当前状态 |
|------|------------|---------|
| GCC海湾国家合计 | **~8-9%** | 严重受阻 |
| 巴林Alba | 全球最大单体冶炼厂之一 | **宣布不可抗力** |
| 卡塔尔 | — | **完全停产** |
| 阿联酋EGA | 全球前5大铝生产商 | 面临停产风险 |

- 伦敦金属交易所（LME）铝价已飙升至$3,418/吨，创近4年新高
- 冲突前全球铝市场已处于约60万吨的供给缺口
- 如果GCC铝产能长期中断，铝价可能突破$4,000/吨

### 2.4 石化产品

- 伊朗是中东主要石化出口国（甲醇、尿素、聚乙烯等）
- 卡塔尔、沙特也是全球石化出口大国
- 中国是最大买家 — 伊朗80%的石油和大量石化品出口至中国

## 三、航运冲击量化分析

### 3.1 运费暴涨

| 航线 | 正常运费 | 当前运费 | 涨幅 |
|------|---------|---------|------|
| 中东→中国 VLCC | ~$218k/天 | $423,736/天 | **+94%** |
| 集装箱 WRS附加费 | 无 | $1,500-2,000/TEU | 新增 |
| 冷藏箱附加费 | 无 | $3,500/箱 | 新增 |
| 海运保险 | 基准费率 | +50%至+100% | 翻倍 |

### 3.2 航运公司应对

| 公司 | 措施 |
|------|------|
| **Hapag-Lloyd** | 暂停所有霍尔木兹海峡通行；加收$1,500/TEU战争风险附加费 |
| **MSC** | 指示船只同时避开曼德海峡和霍尔木兹海峡 |
| **CMA CGM** | 暂停苏伊士运河通行，改走好望角；加收$2,000/TEU |
| **Maersk** | 重新评估刚恢复的红海航线 |

### 3.3 全球航运路线重塑

```
冲突前（2025年底）：
  红海/苏伊士 = 正常（胡塞停火后恢复）
  霍尔木兹    = 正常
  → 全球航运基本正常运转

当前（2026年3月）：
  红海/苏伊士 = ❌ 再次中断（胡塞威胁恢复攻击）
  霍尔木兹    = ❌ 实质关闭（IRGC封锁+保险撤出）
  印度洋      = ⚠️ 战斗区域（美伊海战）
  → 所有中东-亚洲、中东-欧洲航线被迫绕行好望角

影响：
  亚洲↔欧洲：+10-14天航程
  中东→亚洲：部分航线完全中断
  运力被占用→全球其他航线运力也趋紧
```

## 四、"消失"的出口对全球贸易的总体影响

### 4.1 直接贸易损失估算

| 品类 | 每日中断贸易额 | 每月中断贸易额 | 全球贸易占比 |
|------|--------------|--------------|------------|
| 石油（霍尔木兹） | ~$15亿 | ~$450亿 | 全球海运石油的27% |
| LNG（卡塔尔+UAE） | ~$2-3亿 | ~$60-90亿 | 全球LNG的20% |
| 铝（GCC） | ~$0.3亿 | ~$9亿 | 全球铝的8-9% |
| 石化（伊朗+GCC） | ~$0.5亿 | ~$15亿 | 显著份额 |
| 转口贸易（迪拜） | 难以估算 | 显著 | 中东最大转口港 |
| **合计估算** | **~$18-20亿/天** | **~$540-600亿/月** | — |

### 4.2 间接与二阶效应

**1. 全球航运运力紧张**

- 绕行好望角意味着每艘船需多花10-14天 → 等效减少全球可用运力
- 2024年红海危机时，绕行导致全球集装箱运力有效减少约15%
- 当前同时中断两条航线 → 运力紧张可能更严重

**2. 全球供应链传导**

```
一阶效应：石油/LNG/铝/石化直接短缺
    ↓
二阶效应：能源价格上涨 → 生产成本上升 → 全行业传导
    ↓
三阶效应：航运成本上涨 → 所有商品运输成本增加（不仅限于能源）
    ↓
四阶效应：通胀上升 → 央行维持高利率 → 需求抑制 → 经济放缓
```

**3. 迪拜转口贸易中断**

- 迪拜杰贝阿里港是中东最大港口，也是全球第九大集装箱港
- 作为连接亚洲、非洲、欧洲的转口中心，大量非能源商品经此中转
- 港口起火+安全威胁 → 转口贸易受阻，影响远超能源品类

**4. 保险市场系统性退出**

- 不仅是霍尔木兹 — 保险价格上涨影响整个波斯湾、红海、印度洋北部
- McGill and Partners预计保险价格可能翻倍以上
- 即使军事冲突结束，保险市场恢复信心需要**额外3-6个月**
- 这意味着贸易恢复速度将**滞后于**军事降级速度

## 六、历史对比

| 事件 | 贸易中断规模 | 持续时间 | 油价影响 | GDP影响 |
|------|------------|---------|---------|---------|
| 1973石油禁运 | OPEC减产5百万桶/天 | 5个月 | +300% | 全球衰退 |
| 1990海湾战争 | 伊拉克+科威特出口中断（~4百万桶/天） | 7个月 | +130%（峰值） | 美国衰退 |
| 2024红海危机 | 海运贸易12-15%受影响 | ~18个月 | +10-15% | -0.1-0.2% GDP |
| **2026美伊冲突** | **~1,600万桶/天石油+20% LNG+两条航线同断** | **进行中** | **+17%（至今）** | **待定** |

**2026年冲突的贸易冲击规模已超过2024年红海危机，正在接近1990年海湾战争水平。** 如果海峡关闭超过4周，可能成为1973年石油禁运以来最严重的全球贸易中断事件。

## 七、关键假设与不确定性

### 关键假设

1. **沙特和阿联酋的替代管道能正常运营** — 如果这些管道也遭到攻击，替代容量将归零
2. **美国SPR释放足以稳定市场情绪** — 但实际补充全球缺口的能力有限
3. **中国不大规模恐慌性抢购** — 如果中国开始囤积，将推高所有大宗商品价格
4. **冲突不扩展至红海以外的其他航运咽喉**（如马六甲海峡） — 否则全球贸易将面临系统性崩溃

### 最大的未知数

- **海峡实际恢复通航的时间点** — 这是所有贸易影响估算的最关键变量
- **伊朗是否已经或将要在海峡布雷** — 水雷清除需要数月时间，将大幅延长中断期
- **保险市场何时恢复覆盖** — 可能滞后于军事降级3-6个月
- **卡塔尔LNG设施修复时间** — 物理损坏的修复可能需要数周至数月

## 八、结论

### 核心判断

1. **贸易影响的严重性被市场低估**。当前油价仅+17%，市场定价的是4周有限中断。但双航线中断+卡塔尔LNG停产+铝不可抗力的复合冲击，可能造成的贸易损失远超单纯的石油中断。

2. **亚洲是最大受害者**。89%经霍尔木兹的石油流向亚洲，83%的LNG流向亚洲。南亚（巴基斯坦、孟加拉国、印度）面临的冲击可能是灾难性的。

3. **贸易恢复将滞后于军事降级**。即使明天停火，保险市场恢复、航运重新部署、库存重建都需要数月时间。2024年红海危机的教训：胡塞停火后，航运公司花了数月才逐步恢复红海航线。

4. **最容易被忽视的风险**：迪拜转口贸易中断对非能源商品的影响、铝供给短缺对全球制造业的影响、以及保险市场系统性退出导致的贸易恢复滞后。
