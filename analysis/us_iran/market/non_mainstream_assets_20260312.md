## 概述

主流叙事聚焦于原油、黄金和股指。但美伊冲突的传导远比这三者广泛得多。以下按**传导路径**分类梳理所有受冲击的非主流资产。

---

## 一、能源衍生品（油气之外）

### 1.1 氦气 ⬆️ +40%至+100%

| 维度 | 数据 |
|------|------|
| 涨幅 | Bank of America估算现货+40%，部分市场+70%至100%（氦气顾问Phil Kornbluth） |
| 原因 | 卡塔尔是全球第二大氦气生产商（占全球~33%），停产+海峡关闭=供给骤降 |
| 下游影响 | 半导体制造、MRI医疗影像、航天、电子制造 |
| 替代性 | **极低** — 氦气无法合成，全球产能集中且已接近满负荷 |

**分析**：氦气是本次冲突中**最被低估的传导路径之一**。它不像油价那样被广泛追踪，但对半导体产业链的影响可能持续数月。SK海力士-9.52%的暴跌部分反映了这一担忧。

### 1.2 欧洲天然气（TTF） ⬆️ +60%

| 维度 | 数据 |
|------|------|
| 涨幅 | 荷兰TTF期货+59-60%（至3/12），突破€60/MWh |
| 原因 | 卡塔尔LNG停产（全球20%）+霍尔木兹关闭阻断所有海湾LNG出口 |
| 欧洲库存 | 仅~30%（五年低位），需在夏季注入600亿立方米 |
| 前景 | "即使最佳情景，2026年宽松的LNG市场也将推迟至2027年" |

### 1.3 亚洲LNG现货（JKM） ⬆️ 翻倍

| 维度 | 数据 |
|------|------|
| 涨幅 | 亚洲LNG现货价格**翻倍**至$25.40/MMBtu（三年高位） |
| 原因 | 卡塔尔80%的LNG供应亚洲（中日韩台）；不可抗力宣布后现货抢购 |
| 亚欧竞价 | 出现美国LNG货轮从比利时改道至中国的案例 → 欧亚争夺有限LNG |

### 1.4 船用燃料油 ⬆️ 近翻倍

| 维度 | 数据 |
|------|------|
| 涨幅 | 全球前20大加油港重油价格**近翻倍** |
| 原因 | 绕行好望角=更长航程=更多燃油消耗 + 炼油产出中断（巴林） |
| 传导 | 直接推高所有航运成本，间接传导至所有海运商品 |

## 二、化肥与农业 ⬆️ 粮食危机风险

### 2.1 尿素 ⬆️ +26%至+50%

| 维度 | 数据 |
|------|------|
| 涨幅 | 全球尿素价格+26%（$465→$585/MT，至3/11）；部分报道称+50% |
| 美国 | 尿素+21%，氨水+41%（同比）；1吨尿素等价从75蒲式耳玉米升至126蒲式耳 |
| 欧洲 | 尿素€550/吨，硝酸铵钙€370/吨 |
| 原因 | 全球20-30%化肥出口经霍尔木兹；卡塔尔关闭了全球最大尿素工厂 |

### 2.2 氨 ⬆️ +41%（同比）

| 维度 | 数据 |
|------|------|
| 直接影响国 | 印度40%+尿素和磷肥来自中东；巴西近半化肥进口经霍尔木兹 |
| 印度 | 已削减3座尿素工厂产出 |
| 孟加拉国 | 5座化肥厂中**4座关停** |
| 美国 | 化肥供应已比正常季节短缺~25% |

### 2.3 粮食价格传导链

```
化肥价格暴涨（尿素+26-50%，氨+41%）
    ↓
北半球春播季（3-4月）正值关键窗口
    ↓
农民面临选择：高价买肥 / 减少施肥 / 改种低需求作物
    ↓
即使少量减少氮肥使用 → 产量不成比例下降
    ↓
2026年秋季收成可能下降 → 粮价上涨传导至消费者
    ↓
滞后效应：即使战争明天结束，粮食影响将在6-12个月后显现
```

**IFPRI/CFR/CSIS均发出警告**：这可能演变为类似2022年俄乌冲突后的全球粮食安全危机。化肥占农业生产成本的：玉米21%、小麦19%、棉花13%、大豆8%。

## 三、工业金属

### 3.1 铝 ⬆️ +8-10%（最受直接影响的工业金属）

| 维度 | 数据 |
|------|------|
| 涨幅 | LME铝期货+8-10%（至3/12），逼近四年高点$3,370/吨 |
| 原因 | 中东占全球铝产出~9%；巴林Alba（全球最大冶炼厂）减产19% |
| 前景 | BMI上调预测至$3,100/吨；Citi牛市情景$4,000/吨 |
| 反直觉现象 | 中国铝库存反而堆积至130万吨+（2020年以来最高）→ 全球紧缺但中国需求疲弱 |

### 3.2 铜 ⬇️ -6.7%至-8%（需求恐惧压倒供给担忧）

| 维度 | 数据 |
|------|------|
| 跌幅 | LME铜-6.7%（单周最大跌幅近一年），至3/18累计-8% |
| 原因 | 铜的供给端不直接受中东影响，但需求端被**衰退恐惧**压制 |
| 前景 | UBS上调中长期目标至$15,000/吨（2027Q1），但短期受压 |

**铝vs铜的分化揭示了一个关键逻辑**：
- 铝：供给侧直接受冲击（中东产能-9%）→ 涨
- 铜：供给侧不受影响，但需求侧被衰退预期压制 → 跌
- 这说明市场已经开始**定价经济衰退**

### 3.3 其他金属

| 金属 | 方向 | 幅度 | 驱动 |
|------|------|------|------|
| 锌 | ⬇️ | -0.5% | 需求恐惧 |
| 铅 | ⬇️ | -0.7% | 需求恐惧 |
| 铂/钯 | ⬇️ | -10~15%预期 | 汽车需求放缓 |
| 钨 | ⬆️⬆️ | **+500%（过去一年）** | 中国出口限制+军工需求（无人机/导弹） |
| 铁矿石 | ⬆️ | 中等 | 伊朗占全球铁矿石3%+巴林铁球团出口18%受阻 |

### 3.4 钨的极端行情值得单独关注

钨价格过去一年暴涨500%，虽然主要驱动因素是中国出口限制，但美伊冲突**加速了这一趋势**：
- 现代战争消耗大量钨（穿甲弹、无人机零部件）
- 美国武器产能"四倍扩产"进一步推高需求
- 稀土/关键矿物的战略属性被重新定价

## 五、加密货币 — 波动但"韧性"

### 5.1 比特币 ⬆️ +10%（开战以来）

| 维度 | 数据 |
|------|------|
| 表现 | 开战以来+10%（同期标普-2%，黄金-4%） |
| 初期反应 | 2/28打击消息后**闪崩**，但周末传统市场关闭时加密市场承担了"全球风险定价"功能 |
| ETF资金流入 | 过去三周+$21亿 |
| 叙事 | "比特币作为数字黄金/去中心化避险"叙事获得新证据 |

### 5.2 加密市场的特殊角色

| 角色 | 说明 |
|------|------|
| **周末市场** | 传统市场休市时，加密平台成为唯一的风险交易场所。2/28（周六）打击后，比特币交易量暴增 |
| **预测市场** | Kalshi和Polymarket的伊朗冲突合约交易量巨大 |
| **伊朗制裁规避** | 伊朗加密市场$78亿，IRGC关联实体交易活跃。合规风险急剧上升 |

## 八、"隐藏的定时炸弹"— 最容易被忽视的传导

| 排名 | 资产/品类 | 为什么被忽视 | 为什么重要 |
|------|----------|------------|-----------|
| 1 | **化肥/尿素** | 不在金融媒体头条 | 影响全球粮食产出，滞后6-12个月显现，波及数十亿人 |
| 2 | **氦气** | 极小众市场 | 无替代品，直接影响半导体和医疗影像 |
| 3 | **空运费** | 被海运费遮盖 | 部分航线+84%，高价值商品供应链成本急剧上升 |
| 4 | **船用燃油** | 二阶效应 | 翻倍的燃油价格传导至所有海运商品 |
| 5 | **保险成本** | 市场看不到的"隐形税" | P&I撤出=航线关闭；即使恢复，保费将长期高于冲突前 |
