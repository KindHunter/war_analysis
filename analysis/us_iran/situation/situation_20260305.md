## 一、冲突基本画像

### 1.1 冲突各方

| 角色 | 各方 | 核心利益 |
|------|------|---------|
| **进攻方** | 美国 + 以色列 | 彻底消除伊朗核威胁、推动政权更迭 |
| **防御方** | 伊朗（伊斯兰革命卫队IRGC为核心军事力量） | 政权存续、领土完整、报复 |
| **伊朗代理人** | 真主党（黎巴嫩）、胡塞武装（也门）、伊拉克什叶派民兵 | 为伊朗分散压力、开辟多条战线 |
| **被波及国** | 沙特、阿联酋、卡塔尔、科威特、巴林（美军基地所在国） | 避免卷入冲突 vs 盟国义务 |
| **关键第三方** | 中国（伊朗最大石油买家，80%伊朗石油出口至中国） | 能源安全、中东影响力 |
| **调停方** | 联合国（已呼吁停火）、欧盟 | 防止冲突扩大 |

### 1.2 冲突性质

- **国家间战争**：美以联合对伊朗主权国家的军事打击
- **非对称冲突**：美以拥有压倒性空中优势，伊朗以导弹/无人机/代理人/非对称手段回击
- **目标明确为政权更迭**：哈梅内伊被暗杀证实这不仅是有限打击
- **代理人战争同步进行**：真主党、可能还有胡塞武装和伊拉克民兵参与

### 1.3 冲突根源

- **近因触发**：2026年2月谈判破裂 + 美方称伊朗恢复核武计划（注：未提供证据）
- **结构性矛盾**：伊朗核问题自2000年代以来未解决；美国自1979年以来与伊朗政权的根本对立
- **窗口因素**：伊朗国内大规模抗议削弱了政权，被视为政权更迭的"历史窗口"

## 二、三条线追踪

### 2.1 军事线

**当前态势：美以单方面空中优势明确，伊朗以非对称手段反击**

| 指标 | 美以方面 | 伊朗方面 |
|------|---------|---------|
| 打击规模 | 5天内约2,000+次打击 | 大量导弹/无人机发射至多国 |
| 目标类型 | 领导层、军事基地、核设施、导弹基地 | 美军基地（6国）、以色列、迪拜民用设施 |
| 已知战果 | 哈梅内伊身亡，多名高级军事官员被击杀 | 美驻利雅得大使馆遭袭，AWS数据中心瘫痪 |
| 核设施状况 | IAEA称核设施未被命中（与美方声称矛盾） | — |
| 是否有地面行动 | 暂无（纯空中打击） | 不适用 |

**关键判断：**
- 美以拥有绝对空中优势，但纯空中打击能否实现政权更迭存疑
- 伊朗虽无法在常规军事上对抗，但其导弹/无人机库存和代理人网络仍可持续造成痛苦
- IAEA称核设施未被命中——这与作战目标（消除核威胁）存在矛盾，需持续关注
- **暂无地面入侵信号**——但历史经验（伊拉克2003年）显示，没有地面控制的空袭难以实现政权更迭

### 2.2 外交线

**当前态势：外交渠道实质中断**

- 伊朗安全委员会秘书拉里贾尼明确拒绝恢复谈判
- 联合国呼吁停火，但美国拥有安理会否决权
- 中国强烈谴责但暂未采取实质行动
- 美国国内：参议院否决了限制总统战争权力的决议案，特朗普获得政治空间
- 法律争议：多方质疑美国发动打击缺乏法律依据（未经国会宣战授权）

**关键判断：**
- 短期内（1-2周）外交突破的可能性极低
- 哈梅内伊身亡使伊朗内部权力真空，暂时找不到有权做出让步的决策者
- 特朗普"四周"的表态暗示美方可能设想的是有限期打击
- 中国的态度是关键变量——如果中国介入调停或对伊朗提供实质支持，局势可能改变

### 2.3 经济线

**当前态势：霍尔木兹海峡危机是核心经济变量**

| 指标 | 当前状况 | 影响评估 |
|------|---------|---------|
| 霍尔木兹海峡 | IRGC禁航令 + 保险撤出 = 实质关闭 | **极其严重**：全球20%石油、31%海运原油 |
| 布伦特原油 | $83.58/桶（+10-13%） | 如持续关闭可突破$100 |
| 伊朗经济 | 哈梅内伊身亡 + 持续空袭 + 已有制裁 | 近乎崩溃 |
| 海湾国家 | 基础设施遭袭、使馆关闭 | 经济活动受严重干扰 |

**关键判断：**
- 霍尔木兹海峡的关闭是伊朗最有力的经济杠杆
- 但这是"同归于尽"的武器——伊朗自身的石油出口也完全依赖该海峡
- 美国会否用海军强行恢复海峡通航是下一个关键决策点

## 四、情景推演

### 情景A — 持续升级（概率：35%）

- **路径**：伊朗成功对以色列本土造成重大伤亡 → 以色列加倍报复 → 真主党全面开战 → 胡塞武装封锁红海 → 多线冲突
- **触发条件**：伊朗导弹突破以色列防空系统造成大规模平民伤亡
- **后果**：油价破$100-$120，全球经济衰退风险显著上升
- **预警指标**：胡塞武装攻击红海航运、以色列对黎巴嫩大规模地面行动

### 情景B — 有限战争后降级（概率：45%，基准情景）

- **路径**：美以完成主要打击目标（2-4周）→ 伊朗导弹库存耗尽 → 美国宣布"任务完成" → 伊朗被迫接受某种形式的停火 → 进入冻结冲突状态
- **触发条件**：伊朗军事反击能力被实质削弱 + 美国国内政治压力
- **后果**：油价回落至$70-80，但伊朗政治真空带来长期不稳定
- **预警指标**：伊朗导弹发射频率下降、美方开始讨论"退出战略"
- **关键不确定性**：没有地面入侵的情况下，"政权更迭"如何实现？

### 情景C — 快速降级（概率：20%）

- **路径**：伊朗军方/革命卫队内部政变或妥协 → 新领导层寻求谈判 → 国际斡旋促成停火
- **触发条件**：伊朗精英阶层判断继续战斗将导致政权彻底覆灭
- **后果**：油价快速回落，但伊朗长期政治动荡
- **预警指标**：伊朗高级军官公开声明降调、秘密渠道活动增加

## 五、关键假设与不确定性

### 关键假设（如果被打破，分析将失效）

1. **美国不会发动地面入侵** — 如果地面入侵发生，冲突性质根本改变
2. **中国不会对伊朗提供直接军事支持** — 如果中国介入，升级为大国对抗
3. **核武器不会被使用** — 伊朗在2025年打击后核能力有限，但不能完全排除
4. **海湾国家不会主动加入任何一方** — 目前是被动承受而非主动参战

### 最大的未知数

- **伊朗权力继承**：哈梅内伊身亡后谁掌权？鹰派还是务实派？
- **美国的真实退出战略**：打完之后怎么办？是否重蹈伊拉克覆辙？
- **霍尔木兹海峡恢复时间**：海军护航能否在短期内恢复通航？
- **中国的底线**：中国40%的石油进口经霍尔木兹海峡，容忍极限在哪？
